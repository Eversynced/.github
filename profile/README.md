## Eversynced

LATAM product engineers, working inside an instrumented AI delivery framework.

We measure how AI coding agents are actually used, our own use included, and build the tooling
that makes that measurable.

### What's here

**[pheebs](https://github.com/Eversynced/pheebs)** is local-first telemetry for AI coding agents.
It installs as hooks in Claude Code, Cursor, or Codex, writes a JSONL line per event to your own
machine, and sends nothing anywhere until you point it at a backend you control. No source code,
no prompts, no file paths.

It carries the [AI Proficiency Model](https://github.com/Eversynced/pheebs/blob/main/docs/ai-proficiency-model.md),
a versioned document describing the practices and signals that matter when working with agents.

More at [eversynced.com](https://eversynced.com).
